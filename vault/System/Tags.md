# Tags

Tags are the classification; they act as folders. A note can carry several tags, and each hub lists the notes with its tag automatically. When you open a new tag, add it here. Sub-tags under a listed root (`project/<name>`) are valid; projects and courses also get their own row and hub.

| Tag | Hub | Meaning |
|---|---|---|
| `project` | | Projects (`project/<name>`; each gets a hub) |
| `course` | | Courses (`course/<code>`) |
| `learning` | [[Learning]] | Learning topics (`learning/<topic>`) |
| `person` | [[People]] | Person notes |
| `meeting` | | Meeting notes |
| `idea` | | Ideas not yet tied to a project |
| `admin` | | Life admin: paperwork, bills, appointments |
| `daily` | | Daily notes |
| `weekly` | | Weekly review notes |
| `hub` | | Hub (MOC) notes |
| `source` | | Raw sources (transcripts, articles) |
| `claude-memory` | | Mirrored Claude Code memories (read-only) |
| `system` | | System / configuration notes |
